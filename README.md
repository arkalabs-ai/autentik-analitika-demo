# Pratinjau CMS — Law Firm Autentik Analitika

Situs pratinjau WordPress yang berjalan langsung di browser (WordPress Playground). Tidak ada server; perubahan hilang saat tab ditutup.

**Buka pratinjau:** https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/arkalabs-ai/autentik-analitika-demo/main/blueprint.json

- Situs: halaman depan terbuka otomatis.
- Admin (CMS): tambahkan `/wp-admin/` di alamat, sudah masuk sebagai admin.
- Muatan pertama memerlukan sekitar 30–60 detik.

Isi yang disertakan sudah disaring: tanpa foto tim (ditampilkan inisial) dan tanpa data klien. Data tim, legalitas, dan isi layanan masih menunggu konfirmasi kantor. Dibuat oleh ARKA LABS.
